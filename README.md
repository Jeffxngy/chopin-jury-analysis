# Chopin Jury Analysis

Analysis of juror scoring at the 19th International Chopin Piano Competition (Warsaw, 2025).

## Data
Scores from the official [Chopin Institute score sheets](https://www.chopincompetition.pl/en/newsroom/19th-chopin-competition-judges-scores?id=144),
parsed into `data/processed/scores.csv`.

## Setup
```
pip install -r requirements.txt
python scripts/parse_scores.py
```
